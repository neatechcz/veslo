# Veslo v2026.7.6

## What's Changed

- Improves conversation reliability around sending, streaming responses, retry/recovery, and session switching.
- Strengthens local runtime routing so workspace requests, skills, plugins, and server calls stay attached to the intended Veslo runtime.
- Improves recovery from stale or invalid runtime credentials, including clearer request routing and safer fail-closed behavior.
- Refines the session sidebar, recent workspace history, archived sessions, and background prefetching so lists stay fresher across workspace changes.
- Expands MCP, skill registry, and managed plugin handling with stricter route coverage and more consistent server-backed behavior.
- Improves desktop diagnostics and release checks for runtime errors, sidecar packaging, and production build configuration.

## Fixes

- Fixed cases where conversation state, transcript reads, or pending session sends could drift from the selected workspace/session.
- Fixed runtime header/profile handling that could leave local runtime requests using stale or mismatched authentication state.
- Fixed several session archive, sidebar synchronization, workspace activation, and workspace switching edge cases.
- Fixed MCP and skill route handling around registry refreshes, materialization, removals, and hub requests.
- Fixed release workflow validation so production builds check monitoring, sidecar, and bundled-version expectations more consistently.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after desktop assets and latest.json are ready.
- The desktop updater remains on the public Veslo updater channel for stable releases.
