# Veslo v2026.7.11

## What's Changed

- Office document support can now download and install its runtime package when needed, with visible installation progress.
- Managed AI access now handles older account metadata and provider defaults more reliably.
- Support diagnostics have been improved for faster troubleshooting of managed deployments.

## Fixes

- Fixed transient Managed AI access checks unnecessarily blocking the conversation composer.
- Fixed upgrade failures when older Managed AI audit data uses a legacy schema.
- Improved Windows installation by moving the optional office document package to on-demand installation.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after signed desktop assets and `latest.json` are ready.
- The desktop updater remains on the public Veslo updater channel for stable releases.
