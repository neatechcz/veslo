# Veslo v2026.7.3

## What's Changed

- Adds read-only Microsoft SharePoint connector onboarding from the Veslo catalog, including clearer Microsoft sign-in and runtime reload handling.
- Improves message sending reliability by moving more conversation submission, retry, and recovery work into the local Veslo server.
- Strengthens workspace routing and runtime ownership so local workspaces, cloud-backed workspaces, skills, plugins, and Soul updates stay attached to the intended Veslo runtime.
- Expands Napojeni and plugin management with safer managed plugin handling and better workspace materialization.
- Improves release packaging so sidecars are rebuilt for the release and macOS builds can continue when the separate document-runtime package feed has not yet been published.

## Fixes

- Fixed cases where a newly installed managed MCP could require an engine reload while an active run was still using the previous runtime.
- Fixed stale local runtime fallbacks so the app fails closed instead of silently using unsafe or mismatched workspace state.
- Fixed plugin and MCP configuration handling around managed plugins, hidden plugins, policy overrides, and server refreshes.
- Fixed Windows document-runtime packaging and installer wiring for bundled office/document tools.
- Fixed production release gating around document-runtime metadata and sidecar publication.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after desktop assets and latest.json are ready.
- The desktop updater remains on the public Veslo updater channel for stable releases.
