# Veslo v2026.7.1

## What's Changed

- Improves message sending reliability by moving more conversation submission, retry, and recovery work into the local Veslo server, so first messages, queued runs, and interrupted sessions recover more predictably.
- Strengthens workspace routing and runtime ownership so local workspaces, cloud-backed workspaces, skills, plugins, and Soul updates stay attached to the intended Veslo runtime.
- Expands the Napojeni and plugin management flow with clearer plugin policy handling, safer managed plugin installation, and better skill materialization across workspaces.
- Adds read-only Microsoft SharePoint connector support, including clearer Microsoft sign-in and unavailable-connection handling.
- Improves managed AI and AI gateway reliability with stronger runtime authorization, session caching, and startup recovery.
- Adds organization billing and managed AI administration improvements for teams using cloud-backed Veslo services.
- Replaces legacy desktop E2E coverage with the current Tauri Pilot validation path.

## Fixes

- Fixed several cases where the first message in a session could fail, lose draft context, or attach to the wrong workspace after a runtime transition.
- Fixed stale local runtime fallbacks so the app fails closed instead of silently using unsafe or mismatched workspace state.
- Fixed plugin and MCP configuration handling around managed plugins, hidden plugins, policy overrides, and server refreshes.
- Fixed folder-access recovery for local workspaces that need explicit permission before the desktop runtime can operate on files.
- Fixed Windows document-runtime packaging and installer wiring for bundled office/document tools.
- Fixed macOS release packaging gates so distributed builds require signing, notarization, and stapling before publication.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after desktop assets and `latest.json` are ready.
- The desktop updater remains on the public Veslo updater channel for stable releases.
