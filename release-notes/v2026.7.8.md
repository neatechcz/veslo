# Veslo v2026.7.8

## What's Changed

- Improves Windows installer release reliability by checking the signing service before packaging begins.
- Prevents stalled signing requests from blocking a release for an excessive amount of time.

## Fixes

- Fixed Windows release jobs waiting too long when the external signing service does not return a signing operation.
- Improved signing diagnostics and verification for Windows application and MSI artifacts.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after desktop assets and `latest.json` are ready.
- The desktop updater remains on the public Veslo updater channel for stable releases.
