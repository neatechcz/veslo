## Beta Validation Build

This prerelease validates the next Windows installer and local runtime setup before promotion to stable.

## What's Changed

- Improves Windows first-run setup for the managed WSL2 sandbox, including runtime readiness checks before opening a local workspace.
- Prevents personal WSL distributions from being selected automatically when the managed Veslo sandbox is missing.
- Adds a clearer onboarding repair flow for preparing the local Windows sandbox runtime.
- Tightens workspace path handling for Windows sandboxed runs so unsupported network paths are rejected earlier.
- Keeps desktop automation permissions out of the default release capability while leaving them available for E2E builds.
- Improves managed AI gateway routing and runtime readiness checks for local workspaces.

## Validation Focus

- Fresh install on Windows
- MSI and NSIS installer behavior
- WSL prerequisites and VesloSandbox provisioning
- First local workspace onboarding and startup

This prerelease is not intended to replace the stable updater latest release.
