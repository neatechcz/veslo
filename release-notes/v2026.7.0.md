# Veslo v2026.7.0

## What's Changed

- Restores more reliable conversation history when opening workspace-scoped conversations, including clearer unavailable-history handling and recovery from live session history when the active workspace can still provide it.
- Improves conversation run lifecycle recovery so interrupted, aborted, stale, and queued runs reconcile more predictably before queued work resumes.
- Keeps unpublished composer drafts stable while switching targets, reducing lost first-send context and picker conflicts.
- Refreshes Soul, skill, plugin, and runtime ownership flows so workspace-bound actions stay connected to the correct local runtime.
- Streamlines session, dashboard, and server-route internals for more consistent navigation, session loading, and workspace switching behavior.
- Hardens desktop release packaging with stricter monitoring, installer, sidecar, and updater checks.

## Fixes

- Fixed active workspace conversations that could show missing history when the stored transcript snapshot was temporarily unavailable.
- Fixed recovered empty transcripts so later passive reads keep seeing a durable empty state instead of retrying forever.
- Fixed archive actions, archive confirmation, and composer target picker behavior around first submit flows.
- Restored dashboard entries for Soul and plugins.
- Fixed macOS app relaunch behavior after updater install.

## Update Notes

- Desktop installers are published as GitHub Release assets for this version.
- Production updater metadata is published only after the release assets and `latest.json` are ready.
